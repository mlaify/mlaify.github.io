AttackMap

A local-first, open-source defensive security analysis engine. Point it at a repository and it maps the attack surface, traces request-to-sink data flow, and produces prioritized, evidence-anchored findings mapped to MITRE ATT&CK — without sending code off-device. Optional AI review helps triage and explain what to fix first. Output is oriented entirely toward remediation.

AttackMap is under active development, but progress may be slow until more contributors and co-maintainers join. If you'd like to help with the engine, an analyzer, the macOS app, or the docs, open an issue to say hello.

grrclone

A free, open-source macOS menu bar app that connects rclone remotes as Finder volumes. It discovers your remotes, reconnects at login, and repairs mounts after sleep or a network change. No licence key, no phone-home, no kernel extension, no root.
